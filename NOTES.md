# Notes on Conversational LLM Collaboration

## Best Practices for Branching Conversations (ChatGPT)

- Use "Branch in a new chat" whenever you have one or more tangents you want to explore from a single conversation. This allows you to keep the main conversation focused while still exploring different ideas in parallel.
- Immediately rename the new chat after branching, to keep track of the different direction you are exploring. The default is to prefix the chat name with "Branch · ". Days or weeks from now, you won't be able to remember what the different branches were about, so giving them descriptive names is crucial for future reference.
- After you've brought a conversation to it's conclusion, think about renaming it again to reflect it's "done" status, for example by prefixing it with: "Done: ". This will help you keep track of which conversations are still active and which ones are completed, especially as you accumulate more conversations over time.
